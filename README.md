# Министерство сладких и чайных дел Юга

Готовый адаптивный сайт для публикации на GitHub Pages.

## Публикация
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html`, `style.css` и `script.js` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните настройки. GitHub покажет адрес опубликованного сайта.

## Что уже работает
- Сезонные темы: автоматическая по календарю и ручной выбор.
- Каталог с категориями, ценами и наличием.
- Контакты и ссылка на MAX.
- Адаптация под телефон и компьютер.
- Локальная демо-панель для редактирования каталога.

## Важно про администратора
GitHub Pages — статический хостинг. Демо-панель сохраняет товары только в localStorage текущего браузера. Это НЕ защищённая админка: изменения не синхронизируются между посетителями, а исходный код сайта открыт.

Для настоящего аккаунта администратора, общей базы товаров и двухэтапной проверки на `savvadc@gmail.com` подключите Supabase Auth + Supabase Database (или Firebase Authentication + Firestore). Не размещайте пароль, секретный ключ или код подтверждения в `script.js` и не публикуйте их в GitHub. Для production нужно настроить подтверждение входа на серверной стороне.
